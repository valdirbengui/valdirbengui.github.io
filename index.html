A MINHA APRENDIZAGEM

Interfaces Web

A unidade curricular de Desenvolvimento de Interfaces Web permite compreender como construir páginas web utilizando HTML, CSS e JavaScript.

Ao longo da disciplina, desenvolvo competências na estruturação de conteúdos, na criação de layouts responsivos e na implementação de interfaces interativas.

O meu objetivo é criar experiências digitais acessíveis, funcionais e visualmente apelativas.
